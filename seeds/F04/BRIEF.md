# F04: publish a file without overwriting a winner

Repair `main.py` using Python 3.11+ standard library only. Edit only this file. No network or external commands. CLI: `python main.py SRC DST`.

Implement `publish_file(src, dst)`: publish the complete bytes of an existing regular source file to an absent destination. Preserve the source. An existing regular destination with identical bytes is a successful idempotent retry; different bytes cause ValueError and preserve the destination. Return normally on success. CLI success exits 0 with empty stdout; conflict, missing/unreadable source, directory path, identical source/destination paths, or wrong arity exits 2 with nonempty stderr. On failure do not create a destination or alter an existing destination. Source and destination parents already exist; files can be empty, binary, or larger than a small buffer. Symlink and reparse input paths are outside this task's input domain.

Several independent processes can publish different or identical sources to the SAME initially absent destination concurrently, on one local filesystem. Exactly one complete payload must win and must never be replaced, truncated, or deleted by another contender. Every contender whose bytes equal that winner succeeds; all other contenders report conflict. Publication must expose complete bytes atomically. Temporary files must have unique names and be cleaned on normal success or handled errors. No process may clean another process's files. Do not modify unrelated files. Abrupt process death cleanup and power-loss durability are outside this case.
